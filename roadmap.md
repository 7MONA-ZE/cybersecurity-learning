# Cybersecurity Roadmap

This roadmap is designed for absolute beginners who want to build a strong foundation in cybersecurity.

## Phase 1: Foundations
### 1. Networking Basics
- OSI model
- TCP/IP
- IP addresses, ports, protocols
- DNS, DHCP, NAT
- Firewalls and network segmentation

### 2. Linux Fundamentals
- File system basics
- Permissions (`chmod`, `chown`)
- Users and groups
- Shell commands
- Logging and processes
- Package management

### 3. Operating System Security
- User accounts and privilege separation
- Access control
- Patching and hardening basics
- Security settings in Windows and Linux

## Phase 2: Core Security Concepts
### 4. Threats and Vulnerabilities
- Malware types
- Phishing
- Social engineering
- Vulnerability assessment basics
- CVEs and risk basics

### 5. Web Security Basics
- HTTP vs HTTPS
- Cookies, sessions, authentication
- OWASP Top 10 basics
- SQL injection
- Cross-site scripting (XSS)
- Broken access control

### 6. Defensive Security
- Firewalls
- IDS/IPS
- Antivirus and endpoint protection
- Security monitoring
- Log analysis

## Phase 3: Practical Skills
### 7. Hands-on Practice
- Use labs
- Learn one tool at a time
- Practice safely in virtual environments
- Try beginner challenges and CTF tasks

### 8. Tools and Environments
- Wireshark
- Nmap
- curl
- Netcat
- Metasploit basics (ethical context)
- Burp Suite basics
- Linux shell tools

## Phase 4: Specialized Learning
- Incident response
- Cloud security
- Digital forensics
- Threat hunting
- Penetration testing fundamentals
- Governance, risk, and compliance (GRC)

## Suggested Timeline
- Weeks 1–2: Networking + Linux
- Weeks 3–4: Web security and vulnerabilities
- Weeks 5–6: Threats and defensive techniques
- Weeks 7–8: Practice and reflection

## Weekly Goal
Each week, aim to complete:
- 1 topic summary
- 2 notes pages
- 1 hands-on lab
- 1 short reflection

## Suggested Learning Order
1. Learn before you practice
2. Practice before you memorize
3. Write a summary before moving on
4. Repeat difficult topics after a few days

## Example Weekly Checklist
- [ ] Complete one networking lesson
- [ ] Review Linux commands
- [ ] Write notes
- [ ] Run one lab
- [ ] Write a short summary
- [ ] List unclear questions
