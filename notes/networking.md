# Cybersecurity Checklist

Use this checklist to track your progress as a beginner.

## Foundations
- [ ] I understand what cybersecurity is
- [ ] I know the differences between threats, vulnerabilities, and risks
- [ ] I understand basic networking concepts
- [ ] I know the difference between IP, DNS, ports, and protocols
- [ ] I can explain HTTP vs HTTPS
- [ ] I understand the purpose of a firewall
- [ ] I know what authentication and authorization mean

## Linux Basics
- [ ] I can navigate directories
- [ ] I know the difference between absolute and relative paths
- [ ] I understand file permissions
- [ ] I can use `ls`, `cd`, `pwd`, `cat`, `grep`, `find`, `chmod`
- [ ] I know what a process is
- [ ] I can read logs and locate relevant information

## Web Security Basics
- [ ] I understand common web vulnerabilities
- [ ] I know what XSS is
- [ ] I know what SQL injection is
- [ ] I know what CSRF is
- [ ] I know what authentication flaws look like
- [ ] I know why secure coding matters

## Threats and Risk
- [ ] I understand phishing
- [ ] I understand malware basics
- [ ] I know what social engineering is
- [ ] I can explain the difference between a vulnerability and an exploit
- [ ] I understand why patching matters

## Defensive Concepts
- [ ] I know what IDS and IPS are
- [ ] I can explain endpoint security basics
- [ ] I know why monitoring and logging are important
- [ ] I understand the value of least privilege
- [ ] I know why backups matter

## Practice and Learning Habits
- [ ] I keep a learning journal or notes
- [ ] I complete a lab or exercise each week
- [ ] I review my notes regularly
- [ ] I write down questions I still have
- [ ] I practice with a safe environment
- [ ] I focus on understanding instead of rushing
