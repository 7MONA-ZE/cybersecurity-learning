# Linux Fundamentals

## Why Linux matters in cybersecurity
Linux is widely used in servers, cloud environments, and security tools. Many cybersecurity tasks involve Linux terminals, scripting, and log analysis.

## Common Commands
- `ls` — list files and directories
- `cd` — change directory
- `pwd` — print working directory
- `cat` — read file contents
- `grep` — search text in files
- `find` — locate files
- `chmod` — change permissions
- `chown` — change file owner
- `sudo` — run commands as a different user
- `ps` — view running processes

## File Permissions
Linux permissions are typically shown as:
- `r` = read
- `w` = write
- `x` = execute

Example:
- `rw-r--r--` = owner can read/write, others can only read

## Users and Groups
- Root has high privileges
- Non-root users often have limited permissions
- `sudo` allows temporary admin actions

## Basic Concepts
- Shell: command interpreter
- Filesystem: how data is organized on disk
- Processes: running programs
- Logs: records of system events

## Security Relevance
Linux helps you understand:
- privilege escalation concerns
- suspicious process activity
- log review
- access control management
- system hardening basics

## Practice Exercises
- Navigate a directory tree
- Read a text file with `cat`
- Search a file using `grep`
- Change permissions with `chmod`
- Inspect active processes with `ps`

## Beginner Notes
Treat Linux commands like tools; practice them until you can explain what each one does.

## Summary
Linux is one of the most important skills in cybersecurity. It is widely used in security operations and system administration, so learning the basics is essential.
