# CTF Write-Up Folder

Use this folder to document challenge write-ups.

## Write-Up Template
- Challenge name:
- Category:
- Difficulty:
- Goal:
- Tools used:
- Steps taken:
- Result:
- Lessons learned:

## Suggested Process
1. Read the challenge description
2. Attempt the task on your own
3. Record each step you used
4. Summarize the solution clearly
5. Reflect on what you learned

## Beginner Advice
Write down the commands you used and explain why they worked. This helps you build repeatable habits and strengthen your understanding.
