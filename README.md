# Cybersecurity Learning Journal

A beginner-friendly cybersecurity learning repository to organize notes, labs, write-ups, study plans, and resources.

## Purpose
This repository is designed to help you:
- learn core cybersecurity concepts in a structured way
- track your progress over time
- practice with labs and CTF-style challenges
- keep notes that are easy to review later
- build effective habits as a beginner

## Learning Goals
- Understand networking fundamentals
- Learn Linux basics and command-line security tools
- Study common web vulnerabilities and defenses
- Explore malware, threat intelligence, and incident response basics
- Practice safe, ethical, and hands-on learning through labs

## Recommended Beginner Roadmap
1. Networking basics
2. Linux and command-line basics
3. Operating system security
4. Web application security
5. Threats, vulnerabilities, and malware basics
6. Security tools and defensive concepts
7. Incident response and digital forensics basics
8. Hands-on labs and CTF challenges

## Study Structure
- `notes/` — key concepts and study notes
- `labs/` — guided beginner practice scenarios
- `ctf/` — write-ups for challenges
- `resources/` — books, tutorials, and learning links
- `templates/` — repeatable templates for notes and labs
- `roadmap.md` — your structured learning plan
- `checklist.md` — a beginner progress tracker

## Weekly Study Plan
- Monday: Networking and security fundamentals
- Tuesday: Linux + command-line tools
- Wednesday: Web security / OWASP Top 10
- Thursday: Threats / malware / defense basics
- Friday: Hands-on lab or CTF challenge
- Saturday: Notes + writeups
- Sunday: Review + recap

## Daily Learning Template
Use the template in `templates/daily-learning-template.md` when learning anything new.

## Beginner Practice Rules
- Learn one topic at a time
- Take notes immediately
- Apply concepts in practice
- Review your notes weekly
- Write short summaries instead of copying everything
- Focus on understanding, not memorization

## Key Learning Resources
- TryHackMe
- Hack The Box Academy
- OWASP
- Cybrary
- SANS Cyber Aces
- Cisco Networking Academy
- Security-focused YouTube channels and official docs

## Suggested Daily Workflow
1. Read or watch one short lesson
2. Write what you learned
3. Run a small command or experiment
4. Record the result
5. Write one takeaway and one question
6. Repeat the next day
